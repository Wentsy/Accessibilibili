# iPhone 影片保存到相簿（待實機驗證）

日期：2026-09-08。這是新功能候選版，不取代 `CURRENT_ACCESSIBILITY_BASELINE.md` 的已驗證基準。

## 使用者需求與入口

- 使用者主要需要保存目前影片到 iPhone 照片圖庫，不需要在主要頁面增加下載或快取管理按鈕。
- 播放器下方的簡介／評論列之下，直接顯示「保存到相簿」與有文字的「更多選項」。
- 更多選項保留稍後再看、筆記、快取影片、封面、聽音頻、舉報等原有功能，並能進入快取頁。
- 不依賴播放器控制列是否顯示，也不依賴 HeaderControlState 是否仍掛載。
- 進度列與 UP 主關注按鈕之間，原本只有圖示的彈幕開關是已確認的無名稱控制項；補成「顯示彈幕」及 toggled 狀態，共用 semantics 與觸摸操作。
- 使用者描述的位置與該開關吻合，但最終仍需真機確認是否就是使用者遇到的節點。

## 保存流程

1. 取得 iOS 照片圖庫 add-only 權限；拒絕時提供可重新找到的原因。
2. 保存目前 cid／分 P，重用已完成或正在下載的同一 cid；新下載沿用設定的預設畫質與現有帳號權限。
3. 以相簿為目的的新下載，在該畫質優先選 H.264，其次 HEVC；不更改播放的解碼偏好。
4. 相簿下載不以彈幕下載成功為前提，也不把彈幕或字幕燒入影片。
5. DASH 的畫面、音訊都完成後才合成。單檔 MP4 與舊式多段來源走對應路徑。
6. iOS 原生 AVMutableComposition／AVAssetExportSession 產生 MP4，優先 passthrough，失敗時嘗試轉碼。
7. PhotoKit 寫入照片，成功回呼後才顯示「已保存到相簿」。暫存的合成檔清除，離線檔保留以便重試。
8. 同一 cid 的合成／寫入工作去重，並序列化不同影片的相簿匯出。

狀態文字放在主要入口下方，涵蓋下載百分比、音訊下載、合成、寫入、完成、失敗。沒有每秒主動送 VoiceOver announcement；使用者可自行聚焦讀取，避免中斷連續閱讀。

已完成快取的更多選單亦提供「保存到相簿」。不新增獨立快取工具列。

## 完整性與限制

- 保存時應保持 App 在前景；沿用 Dio 下載，不承諾被 iOS 掛起或終止後仍繼續。
- 未完成項目的保存意圖寫入 entry.json；重啟後仍按原有下載佇列行為等待恢復，不自動啟動下載。
- 若程式在下載完成與照片寫入之間被終止，可再次按「保存到相簿」重用完成的檔案。
- 多段 URL 必須保留全部段落與原有順序；iOS 全部下載後合成為 0.mp4。
- 其他平台遇到多段來源會明確報錯，不能把第一段誤標成完整影片；跨平台多段合成不在本次範圍。
- 舊版已標為完成但只有第一段的快取，若長度短於已知預期長度則拒絕匯出，提示刪除後重下。
- 不支援的編碼、FLV／受保護資源與試看片段不能保證可匯出完整影片；必須回報失敗，不假裝完成。
- 長影片合成及相簿寫入需要额外儲存空間。原生匯出失敗保留離線來源。
- 原生檔案工作不得修改 AVAudioSession，亦不得改動背景播放、Magic Tap 或音量觀察。

## 下載安全性修正

- 200 回應若忽略 Range，覆寫部分檔案，不追加重複完整內容。
- 206 必須從本機續傳位移開始，直到遠端已知結尾。
- 416 只有在本機檔案長度與遠端總長一致時才算完成。
- 短於 Content-Length 或空檔案不得算下載完成。
- 中止後的旧回呼不得覆寫新任務狀態；音畫完成回呼不能重複發布完成／相簿匯出。
- 傳入來源的 Referer／User-Agent；序列化 entry.json 更新，防止進度與完成狀態同時截寫檔案。

## 驗證

本環境沒有 Flutter、Dart 或 Xcode，不能聲稱完成編譯、單元測試或真機驗證。

已新增 `test/download_manager_test.dart`，涵蓋忽略 Range、正確续傳、錯誤位移、截短回應，以及相符／不相符的 416。需在具有專案指定 Flutter 版本的環境執行：

```sh
flutter test test/download_manager_test.dart
flutter analyze lib/pages/video/view.dart lib/pages/video/controller.dart lib/http/download.dart lib/models_new/download/bili_download_entry_info.dart lib/services/download test/download_manager_test.dart
```

Hermes 拉取後仍需按專案原有流程編譯未簽名 IPA。

### iPhone VoiceOver 驗收

- [ ] 播放前／播放中／暫停時，左右滑與觸摸都能找到「更多選項」，雙擊能讀到並操作選單。
- [ ] 原先無名称控制項讀作「顯示彈幕」，雙擊切換開關狀態。
- [ ] 能直接找到「保存到相簿」，而主要頁面沒有新增「下載影片」「查看快取」按鈕。
- [ ] 第一次保存權限允許、拒絕、之後重新允許，均有可讀取的結果。
- [ ] 一般有聲影片保存後在照片 App 播放，聲音、畫面及完整時長正確。
- [ ] 多分 P／合集只保存目前分 P；非第一個分 P 也正確。
- [ ] 已完成快取重用；下載中重複點擊不建立重複任务，匯出中不重複寫入。
- [ ] 短暫斷網後再按保存可以恢復，失敗時不誤報成功。
- [ ] 舊式分段影片／HEVC／不支援格式分别測試；長度不足或格式失敗有提示。
- [ ] 保持原有 VoiceOver 與影片聲音共存、背景播放及 Magic Tap 行為。
