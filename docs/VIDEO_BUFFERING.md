# 5708 基底的固定線路緩衝調整

## 基底與狀態

以使用者選定的 2.1.3+5708（`263827f257f69da7ebf606ca9044bbeb1b625105`）為底。
此候選版尚待 Hermes 編譯及 iPhone 實測，不能當作已通過穩定基準。

使用者後續觀察：5708 在穩定網路下開播及進入樓中樓較快；此前新版弱網／背景播放有改善，但不代表全面較佳。樓中樓載入差異的原因尚未確定。

## 本輪取捨

- 移除自動選線、候選線路探測、網路變更探測與自動換線計時器，包括設定入口與對應測試。舊裝置留下的 autoCdn 儲存值不再讀取。
- 影片與音訊 URL 選擇恢復 5708，遵循原手動 CDN 與音訊 CDN 設定；緩衝新增邏輯不選擇或變更線路。
- 保留 5708 既有 HTTP 重連與錯誤處理，並非新增選線或 CDN 測速。
- 保留 60 秒內容預讀目標（依 0.5–4 倍速縮放）、32 MiB 前向與 4 MiB 後向上限，及持續補讀。容量為每個 demuxer 的上限，並非整個 App 的記憶體上限。
- 自動緩衝模式在耗盡後，以約 8 秒實際播放量為續播門檻，取代 5708 的 3 秒。這會讓一次緩衝等久一點，以降低反覆播一下停一下的機會，效果需實测。
- `cache-pause-initial=no` 維持不變，不新增開播或快轉的固定緩衝等待。
- 關閉自動緩衝仍沿用原手動設定；直播與離線設定不變。
- 未採用新版的 120 秒／64 MiB 預讀加倍與 10 秒 HTTP 逾時，降低對 5708 正常網路行為的改動。

## 鎖屏載入

移植已存在的 Dart／原生橋接：僅在仍有播放意圖且一般網路影片正在載入或緩衝時，向 iOS 申請有時限的背景任務。載入恢復、手動暫停、正常結束、播放器釋放、回前景或關閉背景播放時結束任務。到期立即釋放，同一次連續等待不無限續期。

此保護不改寫媒體 URL，不開啟定期檢測，不新增靜音保活。iOS 不保證固定的背景時間，長時間斷網仍可能需要回 App。

## 驗證範圍

已完成 Dart／Swift 語法解析、5708 差異檢查、移除選線後的引用檢查，以及手動線路相關五個檔案逐位元相等核對。另確認正常預讀預算、快速起播及手動／直播緩衝設定保留。Swift 解析器對既有可選型別轉換的誤報以等價括號形式核對。開發環境無 Flutter／Xcode，這些檢查不能替代完整型別分析與 IPA 編譯。

Hermes 編譯後，重點比對相同影片／相同線路下的開播與樓中樓載入速度，再確認弱網反覆緩衝、鎖屏長影片、緩衝時手動暫停，以及 VoiceOver 控制正常。通過後才提升穩定基準。
