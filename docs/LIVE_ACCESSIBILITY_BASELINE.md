# Accessibilibili 直播 VoiceOver 無障礙基準

這份文件專門記錄直播相關的 VoiceOver 行為，避免未來同步 PiliPlus 官方更新時，只驗收一般影片與評論，卻讓直播頁重新退化。

狀態：**程式已實作，待 VoiceOver 實機驗收後才能列為穩定基準。**

相關文件：

- `docs/ACCESSIBILITY_MAINTENANCE.md`
- `docs/VOICEOVER_SEMANTICS_BASELINE.md`
- `docs/ACCESSIBILITY_UPSTREAM_AUDIT.md`（若檔名後續調整，以目前 upstream audit 文件為準）

## 1. 直播推薦卡：一滑一個直播

重點檔案：

```text
lib/pages/live/widgets/live_item_app.dart
```

VoiceOver 左右滑動時，一張直播推薦卡應是一個完整語義節點，不應把封面、觀看數、標題、主播與右下角「更多」拆成多個焦點。

建議朗讀資訊順序：

```text
直播標題，主播，分區，觀看資訊
```

必要規則：

- 一次右滑從上一個直播直接進入下一個直播。
- 不應在兩張直播之間額外遇到一顆「更多」按鈕。
- 視覺上的更多按鈕仍保留給一般觸控使用者。
- VoiceOver 的「更多操作」改由該直播卡的 `CustomSemanticsAction` 提供。
- 點兩下直播卡仍進入原本的直播間。
- VoiceOver 聚焦直播卡時，真實 viewport 應保持與焦點同步。
- 沒有 feedback／更多資料的直播卡，不應虛構「更多操作」。

### 驗收

- [ ] 直播推薦頁每次左右滑只移動一張直播卡。
- [ ] 標題、主播、分區、觀看資訊會一次朗讀。
- [ ] 兩張直播卡之間不再出現獨立「更多」焦點。
- [ ] 有更多操作的直播卡可透過 VoiceOver 自訂操作找到「更多操作」。
- [ ] 執行「更多操作」後仍打開原本的 feedback 對話框。
- [ ] 點兩下直播卡可正常進入直播間。
- [ ] 連續瀏覽時畫面會跟著 VoiceOver 焦點移動。

## 2. 直播聊天的表情／貼圖入口

重點檔案：

```text
lib/pages/live_room/send_danmaku/view.dart
```

直播彈幕輸入列的笑臉 icon 不能只是一張沒有名稱的圖示。

必要規則：

- 貼圖面板關閉時，按鈕朗讀為「表情與貼圖」。
- 提示為「點兩下選擇表情與貼圖」。
- 貼圖面板開啟後，同一位置應改成「鍵盤」。
- 提示為「點兩下返回鍵盤」。
- 視覺點擊與 VoiceOver `onTap` 必須共用同一個切換 callback。

### 驗收

- [ ] 打開直播彈幕輸入介面可以找到「表情與貼圖」按鈕。
- [ ] 點兩下能正常打開直播貼圖面板。
- [ ] 面板打開後按鈕會改念「鍵盤」。
- [ ] 點兩下「鍵盤」可正常回到文字鍵盤。

## 3. 直播貼圖本身必須可朗讀、可操作

重點檔案：

```text
lib/pages/live_emote/view.dart
```

每一張可插入或直接送出的直播貼圖都必須是一個穩定的 VoiceOver 按鈕節點。

標籤來源：

1. 優先使用 API 的 `emoji` 名稱。
2. 去掉最外層的 `[`、`]` 後朗讀，例如 `打招呼 貼圖`。
3. 名稱不存在時至少朗讀「貼圖」。

必要規則：

- 貼圖圖片本身不要額外搶焦點。
- `pkgType == 3` 的貼圖提示「點兩下插入這個貼圖」。
- 其他直接送出的貼圖提示「點兩下送出這個貼圖」。
- VoiceOver `onTap` 與原本 InkWell 共用同一個 `choose()` callback。
- 插入後可朗讀「已插入○○貼圖」。
- 直接送出後可朗讀「已送出○○貼圖」。

### 驗收

- [ ] 左右滑可以逐張找到貼圖，不再只遇到無名稱圖片。
- [ ] 有名稱的貼圖會念出名稱與「貼圖」。
- [ ] 沒名稱時至少會念「貼圖」。
- [ ] 點兩下插入型貼圖能正常出現在輸入框。
- [ ] 點兩下直接送出型貼圖仍能正常送出。
- [ ] 插入／送出後有簡短 VoiceOver 回饋。

## 4. 直播貼圖包分組 Tab

目前直播貼圖資料模型只有 `currentCover` 與類型，沒有可靠的分組名稱，因此不要自行猜測名稱。

目前統一使用：

```text
貼圖包第1組
貼圖包第2組
……
```

必要規則：

- 分組 Tab 必須保留 TabBar 原本的可切換語義。
- 不要為了隱藏封面圖片而把 TabBar 自己的點兩下操作一起排除。
- 如果未來 API 增加可靠分組名稱，可優先改成真正名稱。

### 驗收

- [ ] VoiceOver 可辨識每個貼圖包分組。
- [ ] 點兩下分組後能正常切換貼圖內容。
- [ ] 分組封面圖片不會額外形成重複焦點。

## 5. 與既有全域無障礙機制的關係

直播修正不得破壞既有成熟功能：

- VoiceOver 三指上下翻頁與原生 `pageScrolled` 回饋。
- 焦點與真實 viewport 同步。
- 一般首頁影片卡的一滑一整條。
- 主評論／樓中樓的一滑一整條。
- 播放器進度 ±10 秒與 Magic Tap。

直播頁本身已屬於全域 `VoiceOverPagedScroll` 驗收範圍；未來如果上游重寫 `lib/pages/live/`、`lib/pages/live_room/` 或 `lib/pages/live_emote/`，應重新跑本文件全部項目。

## 6. 完整直播快速驗收

同步官方版或修改直播功能後，至少跑一次：

- [ ] 進入首頁的直播分頁。
- [ ] 連續右滑 10 張直播卡，確認一滑一張且沒有獨立更多焦點。
- [ ] 任選有 feedback 的直播卡測試「更多操作」。
- [ ] 點兩下進入直播間。
- [ ] 打開彈幕輸入介面。
- [ ] 找到「表情與貼圖」並打開。
- [ ] 左右滑至少 10 張貼圖，確認都有名稱或「貼圖」fallback。
- [ ] 實際插入一張普通貼圖。
- [ ] 若有直接送出型貼圖，實際送出一張。
- [ ] 切換至少兩個「貼圖包第 N 組」。
- [ ] 點「鍵盤」返回文字輸入。
- [ ] 回到直播推薦頁，再確認三指翻頁與 VoiceOver 原生翻頁音效沒有退化。

只有完成實機測試後，才把本文件頂部狀態從「待實機驗收」改為已驗證穩定。
