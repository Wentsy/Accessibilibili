# VoiceOver 三指邊界重新整理（待實機驗證）

2026-09-10：首頁推薦（Web／App）、動態各分頁、觀看紀錄各分類，沿用直播彈幕的
`VoiceOverPagedScroll` 邊界 callback。穩定基準不變，待 Hermes 編譯與使用者測試。

- 三指下滑：先往列表頂端翻頁；已在頂端再下滑，呼叫原有重新整理。
- 首頁重新取得推薦，保留使用者「保留上次推薦」設定；底端再三指上滑，取得並追加下一批推薦。
- 動態重新整理目前分頁並更新關注 UP 列表；底端沿用載入更多。
- 觀看紀錄重新整理目前分類，重設分頁游標；底端再上滑，以游標追加更早紀錄。
- 空列表或不足一頁也能觸發邊界操作；沒有更多紀錄時遵守既有 isEnd。
- 請求進行中不重設 page／offset／max／viewAt，避免連續手勢破壞下一頁游標。
- 不修改共用翻頁、原生橋接、Read All 或評論語意；一般翻頁維持 160ms 動畫及原生回饋。

## 實機驗收

1. 三個頁面由中間三指下滑，應先翻頁；到頂端後再下滑才重新整理。
2. 已知關注作者有新動態時，在動態頂端重新整理，無須重啟 App 即可請求最新資料。
3. 首頁頂端刷新推薦；底端上滑追加推薦，原有影片與閱讀位置保留。Web／App 推薦皆測。
4. 觀看紀錄各分類底端上滑載入較早紀錄，直到沒有更多；頂端刷新後仍可繼續載入。
5. 空列表、不足一頁、請求中連續上下滑及失敗後重試均可操作。
6. 左右滑、雙指下滑連續朗讀、三指普通翻頁及底部首頁／動態／我的標籤仍正常。
