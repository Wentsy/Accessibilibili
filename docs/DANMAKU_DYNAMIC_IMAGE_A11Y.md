# 彈幕顏色、動態翻頁與評論原圖分享

日期：2026-09-09。此功能組已由 iPhone VoiceOver 實機驗證，並納入 `CURRENT_ACCESSIBILITY_BASELINE.md`。

## 修改

- 發表彈幕：每個預設色塊提供顏色名稱、啟用的按鈕語義與選取狀態；自訂色顯示色碼，VIP 彩色彈幕有獨立名稱。自訂顏色入口有名稱，內層視覺控制排除重複語義。
- 動態清單：增加兩個螢幕高度的 layout cache，在最後五則開始預取下一批；請求移到 frame 結束，保留 controller 的 isLoading/isEnd 防重複保護。清單與瀑布流皆使用動態 ID key 和 findChildIndexCallback，保留插入／刪除後的節點身份。外層翻頁在末端可以重試載入。
- 評論長按選單：只有包含 content.pictures 的評論提供「分享評論圖片」。單張直接分享；多張可按編號選一張。傳入的是 imgSrc 對應的圖片檔案，不含評論截圖、頭像、文字或 QR code。使用系統分享面板，不會自動傳送到其他 App。
- 長按選單可捲動，避免增加項目後在小螢幕溢出。圖片下載失敗也會關閉 loading 遮罩。

## 實機驗證結果

- Hermes 已修正專案 GetX fork 不支援的 `Get.dialog`，改用專案慣用的 `showDialog`；編譯及 IPA 安裝成功。
- 使用者已確認彈幕顏色、動態翻頁、評論原圖分享，以及「清除彈幕文字」朗讀皆正常。

## iPhone VoiceOver 驗收

- [x] 彈幕各色可左右滑與觸摸找到，朗讀名稱與已選取狀態；雙擊另一色後狀態更新。
- [x] 自訂顏色入口可開啟；VIP 彩色彈幕、原本字號與樣式操作正常。
- [x] 動態單指左右滑跨過多批內容，包含長文、大圖與瀑布流；不會卡在最後一則、跳頂或漏掉下一則。
- [x] 載入慢／失敗後仍可重試；返回動態、刪除動態、切換分類後焦點正常。
- [x] 一張附圖評論長按可直接開啟分享；多張可按編號逐張分享，取消選圖不會分享。
- [x] Be My Eyes 收到純圖片，無頭像與 QR code；普通評論及樓中樓都測試，沒有附圖的評論不顯示該選项。
- [x] 分享取消、斷網下載失敗後仍可操作；既有「保存評論」保留。
